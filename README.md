# Italiano B1

Daily Italian B1 study lessons and a small phone app to review them.

- `days/YYYY-MM-DD.json` – one lesson per day (20 words, 5 sentences, grammar pattern, review). Added automatically each morning.
- `days/index.json` – list of all lessons.
- `index.html` – the app (Today, all days, quiz, search). Hosted on GitHub Pages; add it to your phone's home screen.
- `tools/parse_email.py` – converts the plain-text daily email into the JSON format and rebuilds the index.

Quiz scores and missed words are saved on the phone only.
